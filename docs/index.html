Features

一个窗口，管好所有脚本

新版左侧导航把主页、清日常与设置分成三页，启动、下载、运行检测与路径识别都在对应页完成。

按钮式启动

主页每个游戏一行：未运行时「打开脚本」启动，已在运行则显示「唤到前台」；点图标 / 名称同样生效。鸣潮直接启动正式脚本。

启动游戏

主页每行都有「启动游戏」。未配置启动程序时会先自动检测候选，选中后记住路径与进程名。

下载游戏

行内「更多 ▾」→「游戏下载页」直达官方下载页，也可以在编辑里改成任意链接。

游戏自动检测

编辑卡片或启动游戏时，自动扫描注册表卸载项与常见安装目录，按匹配度列出候选（名称 + 路径 + 来源）一键填入。

可视化添加游戏

顶部「添加游戏」填写名称、脚本路径、游戏路径、官网 / 下载链接与主题色即可生成游戏行，无需改代码。

版本检查

后台检查最新版本，有新版本时显示「本地 → 最新」并高亮「更新」，点开让脚本走自己的更新流程。

Clash Verge

侧边栏按钮一键打开 / 切到 Clash Verge，方便访问 GitHub 与各脚本的官方 API。

路径自动识别

配置优先 → 自动扫描脚本目录 → 预期位置。脚本升级换目录后，点「重新识别路径」一键重扫。

可移植

路径保存为相对路径，整个文件夹换电脑、换盘符后仍然可用；配置只存在本地。

游戏运行检测 v0.6.0

复用各脚本自己的判断方法：一次窗口快照 + 窗口类 / 标题正则 + 进程（路径收窄，可降级），可选 ADB。启动器与云游戏只显示文案，不会再被误报成「运行中」；MaaNTE / MaaEnd 的规则直接读各自 interface.json，脚本更新自动跟随。

  • 运行中（窗口）
  • 运行中（进程）
  • 运行中（ADB）
  • 启动器已开
  • 云游戏运行中
  • 未运行 / 未配置

一键清日常 v0.8.0

清日常页勾选要跑的游戏，按自定义顺序串行执行；每行有自己的「开始清日常 / 停止」按钮与独立状态，某一项运行时其它行不会误显示「清日常中」。任务用各脚本自己已配置好的：ok-ww -t DailyTask -e、MAA LinkStart 热键、MaaNTE / MaaEnd --autostart。

  • 勾选加入队列
  • 顺序队列
  • 每行独立状态
  • 单项超时
  • 随时停止
  • dry-run 预览

前置：先在脚本里预设好日常任务；MAA 需勾选任务队列并配置 LinkStart 热键；MaaNTE / MaaEnd 需填写实例；异环实例没有「启动游戏」前置任务时，请先点主页「启动游戏」。勾选状态与顺序保存在 config.json，自动化操作存在账号风险，请自行评估。

新版界面 v0.8.0

左侧固定导航 +「主页 / 清日常 / 设置」三页：主页用按钮式行启动或唤出脚本；清日常页勾选游戏、逐行独立开始 / 停止；设置页调整强调色、刷新间隔、关闭行为与清日常默认值，保存立即生效。

  • 侧边栏三页
  • 按钮式启动
  • 勾选清日常
  • 每行独立状态
  • 设置即时生效

设置保存在 config.json 顶层 settings：强调色、启动时检查更新、刷新间隔（1.0 / 1.5 / 2.0 秒）、关闭窗口行为、Clash 路径、清日常默认超时 / 预览 / ADB / 完成后关闭。

Interface

深色界面，侧边栏三页

真实 Tk 控件 + Pillow 图标渲染：左侧导航切换主页 / 清日常 / 设置，深色主题与强调色随设置变化。

界面细节

  • ✓侧边栏三页：主页 / 清日常 / 设置，当前页高亮；底部常驻 Hub 状态、运行数与版本。
  • ✓按钮式启动：未运行「打开脚本」，运行中自动变成「唤到前台」；每行都有独立状态与「更多 ▾」菜单。
  • ✓8 种强调色：设置页选择，导航高亮与主按钮随之变化，保存后立即生效。
  • ✓设置持久化：刷新间隔、关闭窗口行为、Clash 路径、清日常默认值写入 config.json，保存失败会提示。

设置页可切换 8 种强调色，也可以改成任意颜色。

Get Started

四步开始使用

不需要安装 Python（使用 exe 时），也不需要改动任何脚本文件。

  1. 1

    下载

    从 Releases 下载 GameHub.exe，或下载源码 zip 后用 Python 运行。

  2. 2

    放到脚本旁边

    解压到脚本所在目录旁，例如 D:\All MAA\GameHub。

  3. 3

    双击启动

    运行 启动游戏中心.bat；需要桌面图标就运行 创建桌面快捷方式.bat。

  4. 4

    添加你的游戏

    点「添加游戏」填写脚本路径与链接；行内「更多 ▾」可以编辑卡片。

目录结构示例

脚本目录名不需要固定：Hub 会在自己所在目录按 exe 文件名自动查找 MAA.exe / MaaNTE.exe / ok-ww.exe / MaaEnd.exe，版本号目录名变了也能找到。

D:\All MAA\
├─ GameHub\                    ← 本程序
├─ MAA-v6.19.0-win-x64\
├─ MaaNTE\
├─ WuwaMAA\ok-ww\
└─ MaaEnd-win-x86_64-v2.33.0\
