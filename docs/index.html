Features

一个窗口，管好所有脚本

启动、下载、更新检查与路径识别，日常操作都在卡片上完成。

启动脚本

点卡片或「启动脚本」拉起脚本；已在运行时自动把它的窗口切到最前，不会重复启动。

启动游戏

每张卡片都有「启动游戏」。未配置启动程序时会先自动检测候选，选中后记住路径与进程名。

下载游戏

卡片底部「下载」直达对应游戏的官方下载页，也可以在编辑里改成任意链接。

游戏自动检测

编辑卡片或启动游戏时，自动扫描注册表卸载项与常见安装目录，按匹配度列出候选（名称 + 路径 + 来源）一键填入。

可视化添加游戏

顶部「添加游戏」填写名称、脚本路径、游戏路径、官网 / 下载链接与主题色即可生成卡片，无需改代码。

版本检查

后台检查最新版本，有新版本时显示「本地 → 最新」并高亮「更新」，点开让脚本走自己的更新流程。

Clash Verge

右上角一键打开 / 切到 Clash Verge，方便访问 GitHub 与各脚本的官方 API。

路径自动识别

配置优先 → 自动扫描脚本目录 → 预期位置。脚本升级换目录后，点「重新识别路径」一键重扫。

可移植

路径保存为相对路径，整个文件夹换电脑、换盘符后仍然可用；配置只存在本地。

Interface

深色界面，卡片即入口

界面由 Pillow 在运行时动态绘制，卡片数量随数据变化，图标、主题色与链接都能自定义。

界面细节

  • ✓8 种主题色：蔚蓝、紫罗兰、青碧、明黄、橙红、玫红、薄荷、雾蓝，卡片顶部光条与按钮随之变化。
  • ✓自动分页：超过 4 个游戏自动分页，两侧箭头翻页。
  • ✓右键菜单：编辑 / 删除卡片；内置卡片不可删除，但名称、路径、链接都能改。
  • ✓Win11 深色标题栏：窗口与卡片由 Pillow 绘制，单实例运行，重复打开会激活已有窗口。

预设主题色，也可以在内置卡片里改成任意颜色。

Get Started

四步开始使用

不需要安装 Python（使用 exe 时），也不需要改动任何脚本文件。

  1. 1

    下载

    从 Releases 下载 GameHub.exe，或下载源码 zip 后用 Python 运行。

  2. 2

    放到脚本旁边

    解压到脚本所在目录旁，例如 D:\All MAA\GameHub。

  3. 3

    双击启动

    运行 启动游戏中心.bat；需要桌面图标就运行 创建桌面快捷方式.bat。

  4. 4

    添加你的游戏

    点「添加游戏」填写脚本路径与链接；内置卡片也可以右键编辑。

目录结构示例

脚本目录名不需要固定：Hub 会在自己所在目录按 exe 文件名自动查找 MAA.exe / MaaNTE.exe / ok-ww.exe / MaaEnd.exe，版本号目录名变了也能找到。

D:\All MAA\
├─ GameHub\                    ← 本程序
├─ MAA-v6.19.0-win-x64\
├─ MaaNTE\
├─ WuwaMAA\ok-ww\
└─ MaaEnd-win-x86_64-v2.33.0\
